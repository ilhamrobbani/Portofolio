## 📂 Portfolio Projects

### 1. Data Preparation Pipeline & Fundamental AI (Python & Excel)
* **Platform/Context:** DQLab Academy
* **Description:** Developed a robust data preprocessing pipeline to clean and prepare retail transaction datasets for data analytics and AI workflows.
* **Key Achievements:**
  * Cleaned retail transaction datasets by correcting text inconsistencies, removing duplicates, and standardizing data formats.
  * Developed Python scripts using Pandas to automatically identify missing values and preprocess datasets.
  * Applied advanced string manipulation techniques to prepare structured and high-quality datasets.
* **Tech Stack:** Python (Pandas), Microsoft Excel

### 2. Market Basket Analysis (Python)
* **Platform/Context:** MySkill
* **Description:** Analyzed customer transaction history to identify purchasing patterns, product associations, and cross-selling opportunities.
* **Key Achievements:**
  * Processed raw transaction histories into highly structured DataFrames using Pandas.
  * Enhanced data quality by identifying and removing canceled orders to prevent skewing the analysis.
  * Performed basket encoding to uncover insights into which products are frequently bought together.
* **Tech Stack:** Python (Pandas)

### 3. Global Salary Analysis (SQL)
* **Platform/Context:** MySkill
* **Description:** Investigated a global salary dataset to uncover trends across different countries, job titles, and experience levels.
* **Key Achievements:**
  * Cleaned and transformed raw global salary datasets using SQL queries.
  * Analyzed salary distribution and trends based on job roles and experience seniority.
  * Identified top-paying geographical regions and historical salary growth patterns.
* **Tech Stack:** SQL

### 4. Retail Transaction Dashboard (Google Looker Studio)
* **Platform/Context:** MySkill
* **Description:** Built an interactive business intelligence dashboard to monitor and evaluate retail sales performance metrics.
* **Key Achievements:**
  * Visualized business KPIs including sales trends, discount impacts, and top product performance.
  * Implemented interactive filters to allow stakeholders to drill down into the data.
  * Analyzed payment method preferences to help optimize business checkout experiences.
* **Tech Stack:** Google Looker Studio

### 5. Pizza Sales Performance (Microsoft Excel)
* **Platform/Context:** HaloTech Academy
* **Description:** Evaluated restaurant sales data to analyze revenue streams, customer demands, and product performance.
* **Key Achievements:**
  * Analyzed restaurant transactions to measure revenue growth and overall product performance.
